Selected work / Product experience

Credit Rise.

A financial UX concept that brings credit review, error discovery and dispute progress into a clearer product dashboard.

View GitHub repository ↗

01 / The design challenge

Making a complicated credit-improvement journey easier to follow.

Credit information can be scattered across bureaus, negative accounts, dispute records and educational resources. The product concept organizes these areas around understandable actions and progress.

Research status

User interviews and usability testing have not been documented for this portfolio case study. Problem statements are design hypotheses, not validated findings.

02 / Design approach

From complexity to a usable workflow.

Review creditIdentify possible errorsPrioritizePrepare disputesTrack progress

The existing AI Labs case study documents a dashboard hierarchy moving from overall score context to bureau views, account details and next actions. Navigation groups features by user intent.

Clear dashboard hierarchy

The interface puts current overview information before detailed account analysis and action tools.

Dispute workflow

Error Finder, Dispute Letters and Dispute Tracker form a logical progression.

Responsible estimates

Illustrative score scenarios are presented as estimates, never guaranteed outcomes.

AI-assisted building

The existing case study describes use of Claude, Lovable, Cursor and GitHub for requirements, prototyping and iteration.

03 / Build and implementation

What the project demonstrates.

The existing AI Labs case study describes dashboard UX, three-bureau visibility concepts, score trends, dispute records, account analysis, payoff planning and educational features. It does not establish that these have live credit bureau integrations or provide professional financial advice.
