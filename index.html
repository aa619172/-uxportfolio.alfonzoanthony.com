About

From troubleshooting systems to designing them

I spent two decades in technical support and systems troubleshooting — diagnosing hardware failures, resolving escalated network issues, and mentoring new hires through complex diagnostic work. That work taught me to look for the root cause of a problem, not just the symptom.

In 2025 and 2026, I completed formal UX design training through Google's UX Design program on Coursera, covering user research, wireframing, prototyping, and usability testing. I'm now applying both skill sets together: the patience to understand a system deeply, and the design craft to make it usable.

I also bring hands-on experience with Figma, design systems, and front-end implementation (React, TypeScript) — so the interfaces I design are grounded in what's actually feasible to build.

Crusoe Rip Pro — Color Separation Interface

Redesigned a legacy desktop tool into a web-based interface built for real operator workflows.

I designed and coded the interface for Crusoe Rip Pro, a RIP color separation tool for screen-print shops. After talking with print operators about friction points in the existing Windows-only software, I built a dark-theme, web-based design in Figma and React that lets operators inspect color channels in real time and export layers with fewer configuration mismatches.
