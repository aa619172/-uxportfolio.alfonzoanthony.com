Mockup Magick.

An evolving creative production platform for apparel mockups, visual asset management and editable product previews.

View GitHub repository ↗

01 / The design challenge

A smoother path from artwork to product presentation.

Creators preparing product imagery must navigate uploads, placement, garment colors, previews and export. This project explores turning those disconnected actions into one predictable workflow.

Research status

User interviews and usability testing have not been documented for this portfolio case study. Problem statements are design hypotheses, not validated findings.

02 / Design approach

From complexity to a usable workflow.

Upload artCreate projectEdit mockupPreviewExport

The documented first-phase workflow supports an image upload, project creation with a sample tee template, editor adjustments and PNG export.

Interactive editor

Konva canvas controls allow changes to scale, rotation and opacity.

Color and export

The first-phase build includes a basic garment tint feature and server-side PNG rendering.

Workspace persistence

Canvas autosave and restore help preserve design state.

Product structure

Authentication, project records, assets and templates provide a foundation for future iterations.

03 / Build and implementation

What the project demonstrates.

The GitHub README documents a Next.js 15 and TypeScript monorepo with Supabase-backed data structures, an editor, a Sharp composition pipeline, initial tests and a deployment plan. Several AI generation, billing and worker features remain scaffolded or future work rather than finished functionality.
